# vc4/interface README

このディレクトリとそのサブディレクトリにはRaspbianのユーザランド
アクセラレーテッドグラフィックスライブラリの一部が移植されており、
以下のAPIを実装しています。

* EGL 1.4
* OpenGL ES 1.1 and 2.0
* OpenVG 1.1
* Dispmanx (proprietary)

最初の3つのAPIに関する詳細については以下のウェブサイトをご覧ください：

```bash
    https://www.khronos.org/
```

主な目的はCircleで2D/3Dアクセラレーション対応のグラフィックスアプリケーションを
利用できるようにすることです。ユーザランドコードで実装されているその他のAPIに
ついては、現在使用されていない標準であることや移植の労力を軽減するため、
ここではサポートされていません。

必要なすべてのグラフィックスアクセラレーションライブラリをビルドするには
このディレクトリで次のコマンドを実行してください。

```bash
	./makeall clean
	./makeall
```

ディレクトリ `addon/vc4/interface/sample/` には参照されているAPIの使用方法を
示すサンプルプログラムがいくつかあります。これらはテストにも使用されています。
さらにいくつかのサンプルを提供する新しいプロジェクト（現在開発中）もあります。

```bash
    https://github.com/rsta2/libgraphics
```

利用可能なテストケースがごくわずかであったため、このアクセラレーテッド
グラフィックス機能のサポートは依然として実験的な段階にあります。ビルドは
AARCH = 32 でしかできません。また、Raspbian ではビルドできません。

このアクセラレーテッドグラフィックス機能の移植用ソースコードは以下のサイトから
取得しました。

```bash
    https://github.com/raspberrypi/userland
```
