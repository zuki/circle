# ADDON_03: wlan/hello_ap

このサンプルはRaspberry Pi 3, 4とZero Wに搭載されているオンボードWLANデバイスを使用して
WLAN公開アクセスポイント (AP) を作成し、データ転送のテスト用のTCPエコーサーバを提供
します。このテストを行うには client/ サブディレクトリのサンプルプログラムを実行する
WLAN デバイスを搭載した別の Raspberry Pi が必要です。作成されるWLAN APは公開
ネットワークを提供するので注意が必要です。無線が届く範囲にいれば誰でも接続できる
可能性があるからです。

必要な設定は現在住んでいる国のISO/IECコード（アルファ2コード）だけですが、サーバと
クライアント双方の kernel.cpp ファイルに設定する必要があります。

メインのCircleライブラリの他に addon/fatfs/ と addon/SDCard のライブラリも必要であり、
WLANライブラリとサーバサンプル、クライアントサンプルをビルドする前にこれらのライブラリを
作成する必要があります。

	cd addon/wlan
	make
	cd sample/hello_ap
	make
	cd client
	make

Raspberry Piの様々なWLANコントローラに対応するため、以下のファームウェアファイルを提供
する必要があります。これらのファイルは以下を実行することによりダウンロードすることが
できます（ "wget" ツールを使用）。

	cd addon/wlan/firmware
	make

ダウンロードしたファイルはサーバとクライアントのブートに使用されるSDカードの 
/firmware ディレクトリにコピーする必要があります。

サンプルプログラムは最初に5回点滅し、imageが正しく読み込まれたことを示します。
初期化後、サーバプログラムはポート7 (echo) で着信TCP接続を待機します。まず、
サーバを起動して初期化が完了するのを待ちます。初期化が完了したらクライアント
コンピュータを起動します。クライアントはサーバに接続し、5秒ごとにメッセージを
送信します。このメッセージはサーバからエコーバックされます。クライアントは
メッセージを受信すると画面に表示します。120秒後に接続は自動的に切断されます。

他のコンピュータ（PCなど）をクライアントとして使用する場合、そのコンピュータは
192.168.1.{2-254}の静的IPアドレス（ネットマスク255.255.255.0）を持っている必要が
あります。公開ネットワークのSSIDは "TEST" です。画面に表示されているように "telnet" 
コマンドを試してください。telnetセッションで何かを入力してReturnキーを押してください。  
入力内容がセッションにエコーバックされて表示されます。telnetセッションを終了するには
セッション開始時に表示されたエスケープキーを押してください。そして、telnetプロンプトで
"quit" コマンドを入力してください。
